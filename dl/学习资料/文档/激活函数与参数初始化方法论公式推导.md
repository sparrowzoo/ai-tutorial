# Sigmoid 与 Xavier 初始化 · 完整数学推导

## 核心逻辑链条

1. **方差一致性要求** → Var(z) = 1（信号稳定传播）
2. **结合方差公式** → Var(z) = n · Var(W) · Var(X)
3. **输入标准化** → Var(X) = 1 → 反推 Var(W) = 1/n
4. **Xavier 初始化** → 正态 σ = √(1/n) 或 均匀 a = √(3/n)
5. **3σ 原则** → Var(z)=1 → 95% 数据落在 [-2, 2] → Sigmoid 梯度有效

| 范围 | 比例 | 含义 |
|------|------|------|
| μ ± 1σ | 68.3% | 约 2/3 的数据 |
| μ ± 2σ | 95.4% | 约 95% 的数据 |
| μ ± 3σ | 99.7% | 几乎全部数据 |

## 第 1 步：方差一致性原理

**目标：让信号在每一层稳定传播**

方差一致性要求：Var(z) = Var(X)

输入标准化后 Var(X) = 1，所以目标为 **Var(z) = 1**

> 为什么是 1？因为标准化后的数据方差为 1，保持方差不变就是保持信号强度不变。


## 第 2 步：线性层输出方差公式

线性层 z = W · X + b

设 z = w₁x₁ + w₂x₂ + … + wₙxₙ，假设独立且均值为 0：

**Var(z) = n · Var(W) · Var(X)**

推导过程：Var(z) = Σᵢ Var(wᵢxᵢ) = Σᵢ Var(wᵢ)·Var(xᵢ)

如果所有 wᵢ 同分布，所有 xᵢ 同分布，则 Var(z) = n · Var(W) · Var(X)

其中 **n = 输入维度**（上一层神经元数量）


## 第 3 步：输入标准化 → 控制 Var(X)

**为什么要标准化？**

- 不同特征的尺度可能相差很大
- 导致 Var(X) 不可控，无法保证 Var(z) 稳定
- 标准化后 Var(X) = 1，公式简化为 Var(z) = n · Var(W)

**标准化方法：**

X_std = (X - μ) / σ

使得 E[X] = 0，Var(X) = 1

> 这是所有初始化方法的前提条件。


## 第 4 步：方差一致性 → 反推 Var(W)

代入目标值：

方差一致性目标：**Var(z) = 1**

代入 Var(z) = n · Var(W) · Var(X)，且 Var(X) = 1：

**1 = n · Var(W)**

**Var(W) = 1/n**

> ✅ **结论：** 权重的方差必须与输入维度 n 成反比。这是 Xavier 初始化的数学根源。


## 第 5 步：Xavier 初始化的两种形式

### 正态分布
- W ∼ 𝒩(0, σ²)
- Var(W) = σ² = 1/n
- **σ = √(1/n)**
- PyTorch: `xavier_normal_`

### 均匀分布
- W ∼ 𝒰(-a, a)
- Var(W) = a²/3 = 1/n
- **a = √(3/n)**
- PyTorch: `xavier_uniform_`


## 第 6 步：3σ 原则 → Var(z)=1 保证 z 落在有效区间

当 Var(z) = 1 时，z 的标准差 σ_z = 1

约 **95%** 的数据落在 [-2, 2] 范围内
约 **99.7%** 的数据落在 [-3, 3] 范围内

### Sigmoid 有效区间
- 有效范围：z ∈ [-2, 2]
- 导数 σ'(z) ≥ 0.1
- **✔ Var(z)=1 → 95% 数据落在有效区**

### Sigmoid 危险区
- 饱和区：|z| > 5
- 导数 σ'(z) ≈ 0
- **✘ |z|>5 是 6σ 以外的事件，概率极小**


## Xavier vs Kaiming 对比

| 对比项 | Xavier 初始化 | Kaiming 初始化 |
|--------|---------------|----------------|
| **适用激活函数** | Sigmoid / Tanh | ReLU / Leaky ReLU |
| **设计目标** | Var(z) = 1 | Var(ReLU(z)) = 1 |
| **补偿需求** | 无 | 补偿 ReLU 砍掉一半信号 |
| **权重方差** | **Var(W) = 1/n** | **Var(W) = 2/n** |
| **正态标准差** | σ = √(1/n) | σ = √(2/n) |
| **均匀分布边界** | a = √(3/n) | a = √(6/n) |
| **PyTorch 方法** | `xavier_uniform_` | `kaiming_uniform_` |


## 最终总结

> **Xavier 初始化 = 输入标准化 + 方差一致性 + 3σ 原则**

1. **输入标准化** 保证 Var(X) = 1，消除数据尺度差异。
2. **方差一致性** 要求 Var(z) = 1，保证信号稳定传播。
3. **方差公式** Var(z) = n · Var(W) · Var(X) 倒推出 **Var(W) = 1/n**。
4. **Xavier 初始化** 正是基于这个数学推导设计出来的。
5. **3σ 原则** 保证 Var(z)=1 时，z 约 95% 落在 Sigmoid 有效区间 [-2, 2] 内。
6. **结果：Sigmoid 梯度有效，避免梯度消失。**
