# 双曲正切求导

# 换1

$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$分子分母同时除$e^x$,分子为$(e^x-e^{-x})/e^x=1-e^{2x}$



$tanh(x)=\frac{1 - e^{-2x}}{1 + e^{-2x}} $

# 凑a 凑b 消除法

我们想把分子里的 $1-e^{-2x}$，变成和分母 $1+e^{-2x}$ 有关的形式，从而把整个分式拆开。

$\frac{a - b}{a + b} = \frac{(a + b) - 2b}{a + b} = 1 - \frac{2b}{a + b}$

或者：

$\frac{a - b}{a + b} = \frac{2a - (a + b)}{a + b} = \frac{2a}{a + b} - 1$



## 那么分先加一个$e^{-2x}$再减掉$e^{-2x}$

公式变为

$tanh(x)=\frac{1 - e^{-2x}+e^{-2x}-e^{-2x}}{1 + e^{-2x}} $ 化简$tanh(x)=\frac{1 + e^{-2x}-2e^{-2x}}{1 + e^{-2x}} $化简$tanh(x)=1-\frac{2e^{-2x}}{1 + e^{-2x}} $ 公式1



## 或者分子  $1-e^{-2x} $ 先加1 再减1

$1-e^{-2x}+1-1$ 变为$2-1-e^{-2x}$ 变为$2-(1+e^{-2x})$



化简 $tanh(x)=\frac{2-(1+e^{-2x})}{1 + e^{-2x}} $ 化简$tanh(x)=\frac{2}{1 + e^{-2x}} -1$ 公式2  所以$1 + e^{-2x}-2e^{-2x}=2-(1+e^{-2x})$



优化$tanh(x)=2*(1 + e^{-2x})^{-1} -1$ 

## 拆公式并逐层求导



$Z=2*Y -1$ 其中$Y=(1 + e^{-2x})^{-1}$   $Z'_Y=2$



$Y=(X)^{-1}$ 其中$X=1 + e^{-2x}$ $Y'_x=-X^{-2}$



$X=1 + e^{V}$ 其中 $V=-2x$ $X'v=e^V$



$V=-2x$  $V'x=-2$

## 链式求导法则

$Z'x=2*(-(1+e^{-2x}))^{-2}*e^{-2x}*(-2)$



$Z'x=-2*(1+e^{-2x})^{-2}*e^{-2x}*(-2)$



$Z'x=\frac{4*e^{-2x}}{(1+e^{-2x})^2}$



用平方差公式 $A^2 - B^2 = (A+B)(A-B)$：

$A+B = (1+e^{-2x}) + (1-e^{-2x}) = 2$

$A-B = (1+e^{-2x}) - (1-e^{-2x}) = 2e^{-2x}$

所以：

$(1+e^{-2x})^2 - (1-e^{-2x})^2 = 2 \cdot 2e^{-2x} = 4e^{-2x}$



$Z'x=\frac{(1+e^{-2x})^2 - (1-e^{-2x})^2}{(1+e^{-2x})^2}$

$Z'x=1-\frac{(1-e^{-2x})^2}{(1+e^{-2x})^2}$



$Z'x=1-f^2(x)$
