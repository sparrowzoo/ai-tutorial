📐 RMSLE 损失函数 维度统一方案

在实现 RMSLE（Root Mean Squared Logarithmic Error）时，最常见的坑就是 预测值 y_pred 和真实值 y_true 维度不一致： y_pred 通常是 (N, 1)，而 y_true 通常是 (N,)。 如果不做处理，PyTorch 会触发隐式广播，导致结果错误或产生警告。

✅ 方案一：统一为 (N,) 推荐

用 squeeze(-1) 把 y_pred 从 (N, 1) 压成 (N,)， 只改预测值，不改真实值，一维到底，最简洁。

def loss_fn(y_pred, y_true):
    y_pred = torch.clamp(y_pred, min=1.0)   # 防止 log(0)
    y_pred = y_pred.squeeze(-1)       # (N,1) → (N,) ✅ 关键

    mse = nn.MSELoss()
    loss = torch.sqrt(mse(torch.log(y_pred), torch.log(y_true)))
    return loss

🔄 方案二：统一为 (N, 1) 备用

用 view(-1, 1) 或 unsqueeze(-1) 把 y_true 从 (N,) 升维成 (N, 1)， 保持和模型输出一致。

def loss_fn(y_pred, y_true):
    y_pred = torch.clamp(y_pred, min=1.0)   # 防止 log(0)
    y_true = y_true.unsqueeze(-1)     # (N,) → (N,1) ✅ 关键
    # 或 y_true = y_true.view(-1, 1) # 等效写法

    mse = nn.MSELoss()
    loss = torch.sqrt(mse(torch.log(y_pred), torch.log(y_true)))
    return loss

⚖️ view(-1, 1) vs unsqueeze(-1)

方法 写法 效果 注意事项
view(-1, 1) y_true.view(-1, 1) 重塑为 (N, 1) 需要张量在内存中连续（contiguous），否则报错
unsqueeze(-1) y_true.unsqueeze(-1) 在最后一维插入新维度 不要求连续，更安全 ✅
✅ 推荐写法： y_true = y_true.unsqueeze(-1)  —  语义清晰，不要求连续，最稳妥。

📊 方案对比

方案 操作 结果 shape 评价
方案一 y_pred.squeeze(-1) (N,) ✅ 推荐 · 只改预测值，不改真实值，最简洁

🎯 总结
推荐用 方案一：
y_pred = y_pred.squeeze(-1)
只改预测值，不改真实值，一维到底，代码最干净。
