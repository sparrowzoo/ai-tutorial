🧠 CNN 卷积层 · 结构 + 映射 完整图解 从“核→特征图”到“一对一 / 多对一 / 一对多”

本文用两张连贯通图，讲透卷积层的内部结构、通道含义，以及三种映射关系在实际场景中的应用。
📐 第一部分：卷积层结构 输入 · 核 · 特征图 · 通道
输入 (R/G/B) 卷积核 输出特征图 点积 → 像素
🧩 核心结论（第一部分）
• 一个卷积核 独立滑动点积 → 一张特征图 → 一个输出通道。
• N 个核 → N 张特征图 → N 个输出通道（堆叠成输出数据）。
• 每个核的 深度 = 输入通道数（图中为 3，对应 RGB）。
🔄 第二部分：三种映射关系 标准卷积 · 分组卷积 · 转置卷积
卷积核 特征图 融合通道 1×1 核
🧩 核心结论（第二部分）
• 一对一：标准卷积，1个核 = 1个输出通道（ResNet）。
• 多对一：分组/逐点卷积，多个核 → 1个融合通道（MobileNet）。
• 一对多：转置卷积，1个核 → 多个输出像素（U-Net）。
• 三种映射分别对应 精度优先、效率优先、上采样任务。
📌 全文总结 从结构到映射，一张网全串起来
🧠 CNN卷积层 · 完整知识框架
• 结构上：输入（多通道）→ 卷积核（深度=输入通道数）→ 点积 → 特征图 → 输出通道。
• 数量上：N 个核 → N 张特征图 → N 个输出通道（标准卷积）。
• 映射上：一对一（标准）、多对一（分组/逐点）、一对多（转置）。
• 场景上：精度选 ResNet，效率选 MobileNet，上采样选 U-Net。
