# 正则化 · 梯度下降 · L1 vs L2 本质拆解

## 核心洞察

正则化本质上是在梯度更新公式中**叠加了一个额外的惩罚梯度**。L1 和 L2 的差异，源于这个惩罚梯度的**数学形式不同**：

- **L1 是常数 (±λ) 的硬阈值** → 产生精确 0（稀疏解）
- **L2 是线性衰减 (λ·w)** → 产生平滑收缩（权重衰减）

---

## 1. 正则化的梯度本质

### L2 正则化 — 线性衰减

$$ \nabla L_{\text{reg}} = \lambda \cdot w $$

- 梯度大小 **正比于** 权重本身。权重越大，惩罚越大；权重越小，惩罚越小。
- 当 $ w \to 0 $ 时，梯度 $ \to 0 $，更新越来越慢，**永远到不了 0**。

**更新公式：**
$$ w \leftarrow w - \eta \cdot \nabla L_{\text{data}} - \eta \lambda w $$

如果忽略数据梯度，纯衰减过程为：
$$ w \leftarrow (1 - \eta\lambda) \cdot w $$

→ 每次乘以一个 **小于 1 的系数**，无限趋近 0，但永远无法精确等于 0。

---

### L1 正则化 — 常数硬阈值

$$ \nabla L_{\text{reg}} = \lambda \cdot \text{sign}(w) $$

- 梯度大小 **恒为 λ**，方向取决于 $ w $ 的符号（$ \text{sign}(w) \in \{+1, -1\} $）。
- 每次更新都减去 **固定的 ηλ**，不受权重大小影响。

**更新公式：**
$$ w \leftarrow w - \eta \cdot \nabla L_{\text{data}} - \eta \lambda \cdot \text{sign}(w) $$

如果忽略数据梯度，纯衰减过程为：
$$ w \leftarrow w - \eta\lambda \cdot \text{sign}(w) $$

→ 每次减去 **固定常数**。当 $ w $ 足够小（$ |w| < \eta\lambda $）时，下一步会直接跨过 0，优化器将其 **精确归零**。

---

## 2. L1 vs L2 全维度对比

| 对比维度 | L1 正则化 (Lasso) | L2 正则化 (Ridge / weight_decay) |
| :--- | :--- | :--- |
| **惩罚项** | $ \lambda \sum \|w_i\| $ | $ \frac{\lambda}{2} \sum w_i^2 $ |
| **惩罚梯度** | $ \lambda \cdot \text{sign}(w) $ <br/>（常数 ±λ） | $ \lambda \cdot w $ <br/>（正比于 w） |
| **小权重行为** | 梯度恒为 λ，**强制推向 0** | 梯度随 w 减小而减小，**缓缓趋近 0** |
| **是否精确为 0** | ✅ **是**（稀疏解） | ❌ 否（仅压缩） |
| **几何形状** | 菱形 / 八面体（有尖角） | 圆形 / 球体（光滑） |
| **最优解位置** | 等高线 **撞尖角**（顶点/低维面） | 等高线与边界 **相切** |
| **典型应用** | 特征选择、高维稀疏建模 | 深度学习防过拟合 (weight_decay) |
| **优化器注意** | 需用近端梯度 / 坐标下降 | SGD 中 weight_decay 即 L2 |

---

## 3. 为什么 L1 能产生精确的 0？

### 数学根源：次梯度 (Subgradient)

L1 正则化项 $ \|w\| $ 在 $ w=0 $ 处不可导。其**次导数**为：

$$ \partial \|w\| = 
\begin{cases}
\{1\}, & w > 0 \\
[-1, 1], & w = 0 \\
\{-1\}, & w < 0
\end{cases}
$$

在 $ w=0 $ 处，次导数是一个区间 $[-1, 1]$。这意味着优化器在 $ w=0 $ 处有一个**“中立区”**：

- 只要数据梯度 $ \nabla L_{\text{data}} $ 落在 $ [-\lambda, \lambda] $ 范围内，$ w=0 $ 就是全局最优解。
- 这个“中立区”的存在，使得 L1 可以把不重要的特征**稳稳地钉在 0 上**，而不是在 0 附近来回震荡。

### L2 为什么做不到？

L2 正则化项 $ w^2 $ 在 $ w=0 $ 处**可导**，导数为 0：

$$ \frac{d}{dw} w^2 = 2w \quad \Rightarrow \quad \text{在 } w=0 \text{ 处导数为 } 0 $$

当 $ w $ 接近 0 时，梯度也越来越小，更新步长越来越短。就像**摩擦力随速度减小而减小**——物体永远在减速，但永远到不了静止。

## 4. 几何直觉

### L2：圆/球

- 约束区域 $ w_1^2 + w_2^2 \le C $ 是一个**光滑的圆**。
- 损失函数等高线（椭圆）与圆边界**相切**于一点。
- 切点不在坐标轴上 → **两个参数都不为 0**。

### L1：菱形/八面体

- 约束区域 $ |w_1| + |w_2| \le C $ 是一个**有尖角的菱形**。
- 损失函数等高线（椭圆）优先**撞上尖角（顶点）**。
- 顶点在坐标轴上 → **有一个参数为 0**。

### 高维空间中的“面”

在三维空间中，L1 的最优解**大概率落在顶点**（只留 1 个特征）。但在**高维空间**（如 1000 维）：

- 顶点只有 $ 2d = 2000 $ 个，但**低维面**（如二维面、三维面）的数量是组合数 $ \binom{d}{k} $，极其庞大。
- 损失函数等高线更容易撞上某个**低维面**，留下 $ k $ 个特征（$ k $ 由 $ \lambda $ 控制），其余清零。
- **这就是 L1 在真实数据中既实现稀疏、又不会“只留 1 个特征”的原因。**

---

## 5. 梯度更新轨迹类比

| | L2 | L1 |
| :--- | :--- | :--- |
| **类比** | **弹簧阻尼** | **削铅笔** |
| **行为** | 越拉越轻，永远回不到原点 | 每刀削掉固定厚度，削到尽头就是 0 |
| **结果** | 无限逼近 0，但不等于 0 | 精确归零 |

---

## 6. 核心结论

> **L1 让参数精确为 0 的根本原因：**
>
> 惩罚梯度是 **常数 ±λ**，不受权重大小影响。每次更新都减去固定值，一旦跨过 0 就硬性归零。
>
> L2 的惩罚梯度是 **λ·w**，越靠近 0 推力越小，只能无限逼近而无法到达。

---

## 7. 工程提醒

| 优化器 | L2 正则化 vs weight_decay |
| :--- | :--- |
| **SGD / 动量法** | weight_decay **完全等价**于 L2 正则化 |
| **Adam** | weight_decay **不等价**于 L2 正则化（被自适应学习率缩放）→ 使用 **AdamW** 修正 |

---

## 8. 总结

| 特性 | L1 正则化 | L2 正则化 |
| :--- | :--- | :--- |
| 稀疏性 | ✅ 强 | ❌ 无 |
| 特征选择 | ✅ 自动筛选 | ❌ 无 |
| 计算稳定性 | ⚠️ 需特殊优化器 | ✅ 稳定 |
| 深度学习常用 | ❌ 少用 | ✅ weight_decay |

**选择建议：**
- 需要**特征选择**或**稀疏模型** → 用 L1 (Lasso)
- 需要**防止过拟合**、**稳定训练** → 用 L2 (weight_decay)
- 深度学习默认 → L2 (AdamW)
