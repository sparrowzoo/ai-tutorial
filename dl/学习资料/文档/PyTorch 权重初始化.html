PyTorch 权重初始化 核心逻辑 · 方差一致性

初始化决定训练成败 —— 其本质是控制每一层输出的方差，防止信号在深层网络中消失或爆炸。
1. 为什么初始化如此重要？

核心问题：梯度消失与梯度爆炸
深层网络中，不恰当的初始化会导致每层输出方差随层数指数级增长或衰减。理想情况下， 我们希望每层输出方差保持一致，即 方差一致性原则。

📉 梯度消失

  • 方差逐层衰减 → 梯度趋近于 0
  • 浅层参数几乎不更新
  • 模型无法学习

📈 梯度爆炸

  • 方差逐层指数增长 → 梯度数值极大
  • 权重更新剧烈震荡
  • 训练发散 → loss 变为 NaN
2. 方差一致性原则
📐 数学推导
设 \( h_l = W_l \cdot h_{l-1} \)，则输出方差 \( \text{Var}(h_l) = n_{l-1} \cdot \sigma_{W_l}^2 \cdot \text{Var}(h_{l-1}) \)
欲使 \( \text{Var}(h_l) = \text{Var}(h_{l-1}) \)，需 \( \sigma_{W_l}^2 = \dfrac{1}{n_{l-1}} \)
结论： 权重的方差应当与输入神经元数量成反比。

然而，不同激活函数会改变信号分布。例如 ReLU 会把一半神经元置零，相当于方差减半，因此需要额外放大权重方差来补偿。
这就是初始化方法必须与激活函数匹配的根本原因。

3. 核心桥梁：gain 因子

gain 是 PyTorch 提供的激活函数推荐缩放系数，用于将通用初始化公式适配到特定激活函数。
调用 torch.nn.init.calculate_gain(nonlinearity) 获取推荐值。

Linear
gain = 1
Sigmoid
gain = 1
Tanh
gain = 5/3
ReLU
gain = √2
Leaky ReLU
gain = √(2/(1+α²))
4. 两大初始化方法对比

🔵 Xavier / Glorot

  • 适用：Sigmoid / Tanh（饱和激活）
  • 均匀：\( U[-a, a] \), \( a = \text{gain} \cdot \sqrt{\frac{6}{n_{\text{in}}+n_{\text{out}}}} \)
  • 正态：\( \mathcal{N}(0, \sigma^2) \), \( \sigma = \text{gain} \cdot \sqrt{\frac{2}{n_{\text{in}}+n_{\text{out}}}} \)
  • init.xavier_uniform_ / xavier_normal_

🟠 Kaiming / He

  • 适用：ReLU / Leaky ReLU（非饱和激活）
  • 均匀：\( U[-b, b] \), \( b = \text{gain} \cdot \sqrt{\frac{3}{\text{fan\_mode}}} \)
  • 正态：\( \mathcal{N}(0, \sigma^2) \), \( \sigma = \frac{\text{gain}}{\sqrt{\text{fan\_mode}}} \)
  • init.kaiming_uniform_ / kaiming_normal_
5. nn.Linear 默认初始化
# torch/nn/modules/linear.py · reset_parameters()
def reset_parameters(self):
    # 权重：Kaiming 均匀分布 (a=√5, 适配 ReLU/Leaky ReLU)
    init.kaiming_uniform_(self.weight, a=math.sqrt(5))
    if self.bias is not None:
        fan_in, _ = init._calculate_fan_in_and_fan_out(self.weight)
        bound = 1 / math.sqrt(fan_in)
        init.uniform_(self.bias, -bound, bound)

结论： 默认使用 Kaiming，因为 ReLU 是目前最常见的选择。
若使用 Sigmoid / Tanh，必须手动替换为 Xavier 初始化。

✅ 核心结论
1. 初始化的本质是 方差一致性——防止梯度消失/爆炸。
2. 激活函数决定初始化方法：饱和函数 → Xavier；非饱和函数 → Kaiming。
3. gain 是适配桥梁：通过 calculate_gain 获取推荐值，传入初始化函数。
4. PyTorch 默认用 Kaiming，因为 ReLU 是主流；若用 Tanh/Sigmoid，需显式改为 Xavier。
