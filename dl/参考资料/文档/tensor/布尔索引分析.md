
# 三维张量 (D, H, W) 布尔索引维度匹配总表

| 筛选目标 | 操作示例 | mask 形状 | 筛选的维度 | 结果含义               |
| :--- | :--- | :--- | :--- |:-------------------|
| **矩阵（整层）** | `tensor[:, 0, 0] > 200` | (D,) | 第0维 | 筛出满足条件的整个矩阵（层）     |
| **行** | `tensor[:, :, 0] > 200` | (D, H)  | 第1维 | 筛出满足条件的行           |
| **列** | `tensor[:, 0, :] > 200` | (D, W)  | 第2维 | 筛出满足条件的列(需转置匹配)    |
| **元素** | `tensor > 200` | (D, H, W)  | 逐元素 | 筛出所有满足条件的数值（摊平为一维） |
---

## 规律总结

| mask 维数 | 对齐位置 | 筛选维度 |
| :--- | :--- | :--- |
| 1维 | 第0维 | 筛矩阵（整层） |
| 2维 | 前两维 | 筛行 或 筛列 |
| 3维 | 全部 | 筛元素（逐元素） |

**核心口诀：mask 有几维，就从左边对齐几维，剩下的那个维度就是要筛的维度。**
