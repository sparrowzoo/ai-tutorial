| 模块 | 训练模式 (`model.train()`) | 推理/验证模式 (`model.eval()`) | 原因 |
| :--- | :--- | :--- | :--- |
| **Dropout** | ✅ 开启，随机丢弃神经元（按概率 p） | ❌ 关闭，所有神经元保留 | 训练时增加泛化性，推理时需确定性输出 |
| **Batch Normalization** | 使用当前 mini-batch 的均值和方差 | 使用训练集全局的滑动平均（running_mean/var） | 推理时只有单条样本，无法计算有效 batch 统计量 |
| **Layer Normalization** | 与训练一致（无区别） | 与训练一致（无区别） | 不依赖 batch 维度，训练/推理行为相同 |
| **数据增强** | ✅ 开启（随机裁剪、翻转、旋转等） | ❌ 关闭（仅做标准化/归一化） | 增强只在训练时需要，推理时需稳定输出 |
| **随机种子** | 通常固定（保证可复现） | 固定（保证结果一致） | 确保实验可复现，减少随机性干扰 |
| **梯度计算** | ✅ 计算梯度，更新参数 | ❌ 不计算梯度（`torch.no_grad()`） | 推理时不需要反向传播，节省内存和计算 |
| **模型参数更新** | ✅ 更新权重和偏置 | ❌ 不更新参数 | 推理时模型固定，不学习 |
| **统计量更新** | ✅ 更新 BN 的 running_mean/var | ❌ 冻结统计量 | 防止推理数据污染全局统计量 |
| **损失函数** | ✅ 需要（计算 Loss → 反向传播 → 更新权重） | ❌ 不需要（只做前向传播，得到预测结果） | 推理时只关心输出结果，不需要衡量误差 |
